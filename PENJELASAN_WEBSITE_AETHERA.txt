1. PENDAHULUAN & GAMBARAN UMUM AETHERA
--------------------------------------------------------------------------------
Aethera adalah platform ruang kerja cerdas (Cognitive Workspace) dan suite 
produktivitas personal generasi baru yang dirancang untuk pelajar, mahasiswa, 
pemrogram (developer), profesional, dan pengguna sehari-hari. 

Aethera menggabungkan kekuatan kecerdasan buatan (AI) terdepan dari Google Gemini 
dengan ekosistem produktivitas yang cair tanpa hambatan (frictionless). Melalui 
Aethera, pengguna dapat:
- Menulis dan merapikan email bisnis, pesan sopan, serta surat lamaran kerja.
- Belajar matematika dan kalkulus langkah demi langkah secara mendalam.
- Mengaudit, menjelaskan, dan memperbaiki bug kode pemrogram secara otomatis.
- Mengelola jadwal dan rutinitas menggunakan Kalender Berbasis Matriks Eisenhower.
- Menulis dan mengorganisir ide menggunakan Ruang Catatan Berbasis Blok ala Notion.
- Memantau tren berita teknologi dunia secara real-time dengan ringkasan instan AI.
- Mendengarkan musik pengiring fokus langsung dari YouTube Music tanpa iklan.
- Berinteraksi dengan Asisten AI yang dapat langsung membuat catatan atau jadwal.

Semua fasilitas ini tersedia 100% gratis, tanpa paywall tersembunyi, dan dengan 
komitmen privasi data pengguna yang terlindungi.

4. FITUR TEMA GELAP & TERANG (DARK / LIGHT MODE)
--------------------------------------------------------------------------------
Aethera dirancang dengan sistem tema ganda (dual theme engine) yang komprehensif:
- Sakelar Sekali-Klik: Tombol ikon Bulan / Matahari di navigasi atas setiap halaman.
- Variabel Desain CSS (Design Tokens): Menggunakan arsitektur CSS modern dengan 
  variabel warna yang terstandarisasi:
  * Dark Mode: Latar belakang hitam obsidian dan slate kosmik (#090a0f, #0f172a), 
    aksen kaca transparan dengan blur 24px, teks putih jernih (#ffffff), dan border 
    halus yang nyaman untuk bekerja di malam hari tanpa membuat mata lelah.
  * Light Mode: Latar belakang putih bersih dan abu-abu modern (#ffffff, #f8fafc), 
    teks gelap kontras tinggi (#0f172a), border tegas bernuansa minimalis, dan bayangan 
    lembut yang nyaman untuk siang hari.
- Anti-FOUT (Zero Flash of Unstyled Theme): Dilengkapi skrip inline di bagian <head> 
  setiap dokumen HTML yang memeriksa 'aethera-theme' di localStorage sebelum halaman 
  selesai dimuat. Hasilnya: tidak ada kedipan warna layar saat pengguna berpindah 
  halaman atau melakukan refresh.
- Sinkronisasi Seluruh Komponen: Mengubah tema di satu halaman secara instan 
  memperbarui tampilan seluruh modal, kartu, pemutar musik, dan menu samping.

5. FITUR MULTI-BAHASA (INTERNATIONALIZATION / i18n ENGINE)
--------------------------------------------------------------------------------
Aethera dilengkapi dengan mesin penerjemah bilingual lokal (i18n engine) berkinerja 
tinggi tanpa ketergantungan pustaka luar (zero-dependency):
- Pilihan Bahasa: Bahasa Indonesia (ID) dan Bahasa Inggris (EN).
- Sakelar Bahasa [EN | ID]: Terletak rapi di baris navigasi (navbar) setiap halaman.
- Reaktif Seketika (Zero Reload): Mengubah bahasa tidak membutuhkan muat ulang halaman. 
  Sistem memicu CustomEvent 'aethera:language-change' yang secara otomatis menerjemahkan 
  seluruh teks, tombol, placeholder kolom input, judul tooltip, dan status auth.
- Kamus Terpusat (Frontend/js/i18n.js): Memuat ratusan kunci terjemahan yang presisi 
  dan alami untuk kedua bahasa.
- Perlindungan Integritas Konten Pengguna: 
  Sistem secara ketat HANYA menerjemahkan antarmuka (UI) website. Catatan pribadi yang 
  dibuat pengguna di modul Notes serta judul acara kalender yang dibuat pengguna di 
  modul Calendar TIDAK AKAN PERNAH diubah atau diterjemahkan secara paksa. Hal ini 
  menjaga orisinalitas data pengguna 100%.

6. ARSITEKTUR BASIS DATA & SINKRONISASI MULTI-PERANGKAT (DATABASE)
--------------------------------------------------------------------------------
Aethera menggunakan arsitektur basis data lokal persisten yang cerdas dan efisien:

6.1. PENYIMPANAN SERVER (Backend/db.json)
- Format JSON Terstruktur: Seluruh data pengguna disimpan di file 'Backend/db.json'.
- Partisi Pengguna Terisolasi: Setiap akun pengguna memiliki ruang data tersendiri:
  * users[username].id: ID unik pengguna.
  * users[username].username: Nama pengguna akun.
  * users[username].displayName: Nama tampilan yang ramah.
  * users[username].salt & hash: Kriptografi keamanan kata sandi.
  * users[username].data.calendar: Koleksi seluruh acara kalender pengguna.
  * users[username].data.notes: Koleksi seluruh catatan berbasis blok pengguna.
  * users[username].data.chats: Riwayat interaksi dengan asisten AI.

6.2. SISTEM AUTENTIKASI AMAN (LOGIN & REGISTER)
- Registrasi Akun: Pengguna baru dapat mendaftarkan akun di halaman login.html.
- Kriptografi Keamanan: Password pengguna dienkripsi di sisi server menggunakan 
  algoritma kriptografi bawaan Node.js (crypto) dengan teknik Salt acak dan Hashing 
  SHA-512. Password dalam bentuk teks polos (plaintext) tidak pernah disimpan di disk.
- Session Token: Setelah login berhasil, server menerbitkan token sesi yang valid 
  dan aman untuk mengotorisasi sinkronisasi data.

6.3. SINKRONISASI DUA ARAH (TWO-WAY SYNC)
- Mode Tamu (Guest Mode): Jika pengguna belum login, data tetap tersimpan secara 
  lokal di browser melalui localStorage (aethera_calendar_guest, aethera_notes_guest).
- Sinkronisasi Saat Masuk (Login Sync): Saat pengguna masuk ke akun mereka, data 
  terbaru di server langsung ditarik (pull) dan disinkronkan ke antarmuka klien.
- Push Otomatis Real-Time: Setiap kali pengguna menambah catatan, mengubah isi blok, 
  mencentang to-do, atau memindahkan acara kalender, sistem klien (Frontend/js/user-db.js) 
  langsung mengirimkan pembaruan data secara otomatis ke server melalui endpoint 
  API '/api/user/sync'.

6.4. KEMAMPUAN MULTI-PERANGKAT (MULTI-DEVICE READY)
- Server Backend Aethera secara otomatis mendeteksi alamat IPv4 jaringan LAN lokal 
  melalui fungsi 'getLocalNetworkIp()'.
- Anda dapat menyalakan server di laptop atau komputer Anda, lalu membuka Aethera 
  dari ponsel pintar (smartphone) atau tablet yang terhubung ke jaringan Wi-Fi yang sama.
- Catatan dan jadwal yang Anda buat di laptop akan langsung muncul di smartphone Anda 
  begitu Anda login ke akun yang sama!


--------------------------------------------------------------------------------
7. KEAMANAN & PRIVASI SISTEM
--------------------------------------------------------------------------------
Keamanan dan privasi adalah pilar utama perancangan Aethera:
- Kunci API Tersembunyi (Server-Side AI Proxy): Kunci Google Gemini API (GEMINI_API_KEY) 
  disimpan secara eksklusif di dalam file 'Backend/.env' di server. Klien di browser 
  TIDAK PERNAH memiliki akses langsung ke kunci API ini. Semua permintaan inferensi 
  AI dikirim ke endpoint internal '/api/ai/chat' di mana server yang memvalidasi dan 
  meneruskannya ke Google.
- Proteksi File Internal (403 Forbidden): Server Node.js Aethera secara tegas 
  memblokir permintaan web yang mencoba mengakses berkas rahasia seperti:
  * Backend/db.json
  * Backend/.env
  * .git / .gitignore
  * Seluruh file konfigurasi backend.
  Upaya akses dari browser ke file-file tersebut akan langsung dibalas dengan kode 
  status keamanan '403 Forbidden'.
- Isolasi Data Antar Pengguna: Pengguna yang login dengan akun A tidak akan pernah 
  bisa melihat atau mengubah kalender dan catatan milik akun B.
